# Надо сделать идеально

Одностраничный сайт о взгляде на перфекционизм в работе и учёбе. На весь экран проигрывается фоновое видео, поверх него — крупный заголовок. При наведении на заголовок появляется сноска: «На самом деле нет. Важнее — научиться ошибаться».

Учебный проект [Яндекс Практикума](https://practicum.yandex.ru/), курс «Фронтенд-разработка».

**Демо:** https://dariaef675.github.io/nado_sdelat_idealno-main/

## Технологии

- HTML5: семантическая разметка, метатеги, Open Graph, фавиконки
- CSS3: Flexbox, позиционирование, псевдоэлементы `::before` и `::after`, состояние `:hover`
- Подключение локальных шрифтов через `@font-face` (Raleway, форматы WOFF и WOFF2)
- Фоновое видео с постером (`<video>`, `object-fit: cover`)
- Именование классов по методологии БЭМ

## Структура проекта

```
├── index.html          разметка страницы
├── styles/styles.css   стили
├── fonts/              шрифты Raleway и font.css
├── images/             иконки, постер видео, изображение для соцсетей
└── video/              фоновое видео
```

## Как запустить

Сборка не требуется. Склонируйте репозиторий и откройте `index.html` в браузере:

```bash
git clone https://github.com/dariaef675/nado_sdelat_idealno-main.git
cd nado_sdelat_idealno-main
open index.html
```
